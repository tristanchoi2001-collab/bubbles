## 비용 규칙 (최우선, 사용자 지시 2026-10-23)
- 추가 비용이 생기는 외부 서비스·유료 API·유료 검색·유료 도구는 쓰지 않는다. 무료 공개 API·공개 웹페이지만 쓴다.
- API 키가 환경변수에 있어도 유료 서비스에 연결하지 않는다.
- 유료 논문은 결제·우회하지 않는다. 공개 초록·저자 공개본·오픈액세스만 쓴다. 차단되면 유료 프록시·우회를 쓰지 않는다.
