## ⑤ 실험 조건표와 분석 계획

### 5.1 실험 조건 (제안. 확정 값은 ⑥의 답을 받은 뒤 고친다)
| 항목 | 제안 | 이유 |
|---|---|---|
| 갭 H | 0.3, 0.7, 1, 3, 7 mm (같은 철 블록·같은 폭·같은 가열 길이) | 갭만 바꿔야 갭 효과를 말할 수 있다. Co = Lc/H가 9.1~0.39(1.4 자릿수) |
| 유효 갭 | 갭마다 단상 층류 ΔP로 H_eff 역산 + 간극 게이지 | 0.3 mm는 10 µm 오차가 ΔP 10% 오차 |
| 덮개 | 두꺼운 유리(또는 두꺼운 아크릴), 내압에서 처짐 확인 | 아크릴 5 mm·폭 50 mm·50 kPa면 21 µm 처짐 |
| 방향 | 수평, 아래 가열, 위 투명 덮개(확인 필요) | 수직이면 웅덩이 논리(Lc·2Lc)가 달라진다 |
| 액체 | 탈이온수, 수온·전도도 기록 | 오염은 메니스커스 마찰 계수를 2~3배 바꾼다(추정 5장) |
| 액체 겉보기 속도 j_L | 0.05, 0.1, 0.2, 0.4, 0.8 m/s (로그 간격) | 1 mm는 층류, 7 mm는 층류~난류를 걸친다. Ca 0.0007~0.01 |
| 기체 | 공기 주입: 체적 유량비 β = j_G/j 0.05~0.6, 5단계. 비등이면 열유속 5단계 | 기포류 → 슬러그류 |
| 열유속 q | 공기-물: 벽 과열이 비등 시작 전(벽 온도 < 약 80 °C)이 되게. 비등: CHF의 절반까지 | 두 메커니즘을 섞지 않는다 |
| 단상 기준 | 모든 갭 × 모든 j_L에서 ΔP와 h | 열손실 보정, 이상류 배율의 분모 |
| 무유동 영점 | 갭마다 정수압 영점 | 7 mm에서는 1° 기울기(17 Pa/0.1 m)가 마찰보다 클 수 있다 |
| 반복 | 대표 점 20%를 다른 날 반복 | 재현성 |
| 영상 | 운전점마다 2000~5000 프레임. 프레임당 이동이 이웃 간격의 1/3 이하가 되는 fps | 추적 오연결 방지(트래커 경험상 이동/간격 비 < 0.5) |
| 보정 | 철 바닥 높이에 보정판(px/mm), 갭마다 | 7 mm는 덮개 밑 기포와 바닥의 배율 차 확인 |
| 동기 | 카메라 노출 신호(TTL)를 DAQ로 기록, 또는 DAQ가 켜는 LED를 화면 안에 | 압력 변동과 기포 통과를 맞춘다 |
| 자료 수집 | ΔP 1 kHz 이상(스펙트럼), 열전대 10 Hz 이상 → 운전점별 평균 | 열전대는 1 Hz 이상 변동을 못 본다(추정 9장) |

- 실험점 수: 5 갭 × 5 j_L × 5 β ≈ 125점 + 단상 25점 + 반복.
- **순서 제안**: ① 이미 있는 0.3·0.7 mm 단열 자료로 영상 지표·압력 강하 모델(마찰 계수 c)을 먼저 맞춘다. ② 같은 방법을 1/3/7 mm 단열로 넓힌다. ③ 가열 실험으로 열전달을 본다.
- 같은 부피 유량 Q로 비교하는 점도 몇 개 넣으면 "같은 펌프 조건에서 갭의 효과"도 보여 줄 수 있다.

### 5.2 영상 지표 (운전점마다, 시간 평균 + 신뢰구간)
| 지표 | 계산 | 필요한 것 | 쓰는 곳 |
|---|---|---|---|
| 투영 기공률 α_p | Σ기포 면적 / ROI 면적, 프레임 평균 | 검출 | 기본 |
| 부피 기공률 α | 기포마다 모양 모델(팬케이크 / 구 / 웅덩이)로 부피 → 합 / ROI 부피 | H, 투영 직경 d_p | 드리프트 플럭스, 액체 가속 |
| 수 밀도·크기 분포 | 개수/면적, d_p 분포, d32 | 검출 | 양식 기술 |
| 계면 길이 밀도 Γ, Γ_c | Σ둘레 / 면적. Γ_c는 아래 벽에 닿는 기포만 | 윤곽 | 압력 강하 항 |
| 접촉 면적 비율 φ_c | 아래 벽에 닿는 기포의 면적 / ROI 면적 (수평이면 d_p ≥ H인 기포, 7 mm는 0) | H, d_p | 열전달 |
| 통과 빈도 f | 각 열전대 위 작은 창을 지나는 기포 수 / 시간 | 추적 | 표면 갱신, 3구역 모델, 압력 스펙트럼 비교 |
| 크기별 C0(d) | 추적 속도 V / j (크기 구분별 중앙값) | 추적, 유량계 | 마찰 계수 c, 갇힘 주곡선 |
| 기포·슬러그 길이 | 흐름 방향 길이, 액체 슬러그 길이 | 검출 | Taylor 흐름 모델 |
| 합체·분열률 | 이벤트 수 / (면적·시간) | 추적 | 양식 기술 |
| 미세 거품 면적 | 개별 추적이 안 되는 거품 무리의 면적 비율(별도 클래스) | 검출 | 따로 보고 |

- 불확도
  - 경계 ±1 px → 크기별 면적·둘레 오차(작은 기포일수록 큼).
  - 연결 감사(`4_link_audit.py`) → 크기별 오연결률 → C0·통과 빈도의 오차.
  - 프레임 간 상관을 고려한 블록 부트스트랩 → 시간 평균의 신뢰구간.
  - 위 오차를 모델 계수(c 등)까지 부트스트랩으로 전파한다.

### 5.3 모델 비교 절차
1. 압력 강하
   - 측정 ΔP − (입출구 + 가속 + 정수압) = 마찰 ΔP.
   - 기존 상관식(Chisholm 계열의 좁은 직사각 유로용, Kim & Mudawar 범용식 등)과 비교 → 갭별 잔차를 본다.
   - 잔차를 Γ_c·σ·Ca^(2/3)/H에 대해 그린다 → 계수 c를 맞춘다.
   - 영상 C0(X) 곡선에서 따로 얻은 c와 비교한다("한 계수, 두 관측").
2. 기포 운동학
   - C0를 X = (H/d)·Ca^(−1/3)에 대해 그린다. 1·3 mm가 한 곡선에 모이는지, 7 mm는 벽 근처 가지로 따로 가는지 본다.
3. 열전달
   - h_TP/h_1φ를 φ_c, f, α에 대해 그린다.
   - 후보 모델: 액체 가속, 표면 갱신(φ_c·f), Taylor 흐름 모델, (비등이면) 3구역 모델에 영상 빈도 대입, 핵비등 + 액막 증발.
   - 맞춘 상수가 가장 적은 모델로 세 갭을 함께 설명하는지 본다.
4. 일반화 시험: 두 갭으로 맞추고 나머지 한 갭을 예측한다(갭 하나 빼기 검증).

## ⑥ 사용자에게 확인할 질문 (중요한 순서)
0. **0.3·0.7 mm 단열 실험 자료**: 어떤 채널(투명/철)인가? 무엇을 쟀나(ΔP, 유량, 영상, 압력 변동)? 운전 범위와 자료 형식은? 우리 파이프라인으로 처리한 영상이 있는가? 1/3/7 mm 단열 자료도 있는가?
1. 기포는 공기 주입인가, 비등인가? 둘 다 할 계획인가? 공기라면 어디서 어떻게 넣는가?
2. 채널은 수평인가(아래 철 블록 가열, 위 투명 덮개)? 수직이나 경사라면 각도는?
3. 채널 치수: 폭, 길이, 가열 구간 길이와 위치, 입구(혼합부)·출구 구조.
4. 운전 범위: 액체·기체 유량(또는 질량 유속), 열유속, 입구 수온, 탈기 여부.
5. 압력: 차압계 종류·범위·정확도, 탭 위치(가열 구간 안쪽인가), 절대압 측정 여부.
6. 열전대: 종류·지름, 개수, 깊이와 흐름 방향 위치, 철의 종류(탄소강/스테인리스), 히터 전력 측정과 단열.
7. 카메라: fps, 노출 시간, 화소당 mm(보정판 유무), 시야가 가열 구간의 어디인가, DAQ와 동기 여부.
8. 덮개 재질(아크릴/유리)과 철 바닥의 젖음성(물 접촉각), 표면 거칠기.
9. 다섯 갭(0.3/0.7/1/3/7 mm)이 같은 블록·같은 시야·같은 열전대 배치인가? 가열 실험도 다섯 갭 모두 하는가?
10. 목표: 학위 논문인가, 학술지 투고인가(목표 학술지와 일정)?
