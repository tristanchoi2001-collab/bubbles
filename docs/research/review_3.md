## 1. 독립 유도 (노트를 보기 전에 함)

### 1.1 타원 하나와 평균장 (점검 1)
- 퍼텐셜 φ = −Kp(K = H²/12μ). 기포 경계에서 ∂φ/∂n = V·n_x, 멀리서 φ → Ux. 흐름 방향 반축 a, 가로 반축 b.
- 타원 좌표로 풀면 ∮φ n_x ds = πb[U(a + b) − Vb]. 기포에 매기는 유효 구배(속도 단위)는 U(1 + b/a) − V·b/a다.
- 이 값이 0이 되는 V = U(1 + a/b)다. Taylor–Saffman 속도와 같다. 원이면 2U − V다.
- 평균장(기포가 받는 장 = 기포 사이 액체 평균 U_m): K·G = (1 − α)U_m + α[U_m(1 + b/a) − sU_m·b/a], j_L = (1 − α)U_m.
  → **E = cα/(1 − α) − (c − 1)B, c = 1 + b/a**. 노트와 같다.
- 이것은 정렬 타원의 Maxwell–Garnett 공식과 정확히 같다. 대응: 국소장의 s배로 움직이는 기포 = 전도도 ε = s(1 − N)/(1 − Ns)인 포함물(N = b/(a + b)). 원이면 ε = s/(2 − s), λ = s − 1 = (ε − 1)/(ε + 1). sympy로 차가 0이었다.
- 한계: α 1차는 엄밀하다. α/(1 − α) 꼴은 "상관 구멍이 기포와 같은 모양"이라는 MG 가정이다. 모든 기포의 b/a와 방향이 같아야 한다.
- 임의 모양은 c = 1 + C_A(2차원 부가질량 계수)다. 같은 경계 적분에서 바로 나온다. I81과 같다. 무작위 방향(등방) 타원은 C_A 평균이 (b/a + a/b)/2 ≥ 1이라 멈춘 경우 y ≥ 2가 되어 HS와 맞는다.

### 1.2 판별 평면 (점검 2)
- y = E(1 − α)/α, x = 1 − s̄, s̄ = B(1 − α)/α. 폐합은 y = c − (c − 1)(1 − x) = 1 + (b/a)x. 맞다.
- 층류 분리류(u_L = j_L/(1 − α)에서 단상 마찰): φ_L² = 1/(1 − α), E = α/(1 − α), y = 1. 맞다.
- 액체 점도 균질류: E = B, y = B(1 − α)/α = s̄ = 1 − x. 맞다.
- 유량만 쓰는 상관식: 같은 B에서 E 고정이면 y = E·s̄/B = (E/B)(1 − x). 맞다.
- 구조 모델은 (0, 1)을 지난다. 유량 상관식은 (1, 0)을 지난다. 액체 점도 균질류는 E/B = 1인 유량 상관식이라 둘 다 지난다. 다른 균질 점도는 다르다(Dukler: E/B = μ_G/μ_L ≈ 0.018, Beattie–Whalley: E/B = 2.5/(1 + B)).

### 1.3 α 오차 (점검 3)
- r = (1 − α)/α로 두면 x − 1 = −Br, y = Er다. α가 바뀌면 r만 바뀐다. 그래서 점은 (1, 0)을 지나는 직선 위로 움직인다. 1차가 아니라 **정확**하다.
- 모든 점의 r이 같은 배율 (1 + ε)로 바뀌면 (1, 0) 중심의 닮음 변환이다. 기울기 k는 그대로, 절편은 1 + ε(1 + k)가 된다.
- 그러나 α' = α(1 + δ)면 ε = −δ/((1 − α)(1 + δ))라 α마다 다르다. 두 점 사이 기울기는 k + (1 + k)·Δε/Δx가 된다.
  - r9의 세 예상 점(α 0.38/0.19/0.14): δ = ±10%에서 맞춤 기울기 0.92/1.08, 절편 0.77/1.31.
  - 테두리 두께 오차 δr이면 δ ≈ 2δr/R이다. δr = ±0.1H에서 d/H 3/10/30의 δ는 ±13.8/±4.0/±1.3%다. 기울기는 4번 행의 값이 된다.
- 무작위 α 오차: 각 점이 기울기 −y/(1 − x) < 0 방향으로만 흩어진다. 그래서 기대값으로 양의 기울기를 만들지 못한다. 맞다. 다만 참 기울기를 줄일 수는 있다(흩어짐이 x 퍼짐과 비슷하면). I54 설계(x 퍼짐 약 1.2)에서는 작다.

### 1.4 멈춘 기체의 경계 (점검 4)
- 깊이 평균 Darcy에서 불투과 기체 = 2차원 전도 문제의 절연체(Neumann)다. 경계를 그대로 쓸 수 있다.
- Wiener(어떤 배치든): K_eff ≤ (1 − α)K → E ≥ α/(1 − α). 등호는 흐름 방향 띠.
- 2차원 HS(통계적 등방): K_eff ≤ K(1 − α)/(1 + α) → E ≥ 2α/(1 − α). 등호는 피복 원판 집합(= 원형 MG). 맞다.
- 단서
  - HS는 등방일 때만이다. 흐름 방향으로 긴 멈춘 기체나 줄 선 배치는 y가 1까지 내려간다.
  - 기체가 멈춘 통로로 흘러도 액체에게는 여전히 불투과라 경계는 성립한다. 그러나 점은 x < 1에 찍히고 y = c 수평선에 놓인다(15번).
  - 2차원에서 등방으로 이어진 기체 망은 액체를 끊는다(E → ∞). 경계와 모순은 없다.
  - 가장자리 3차원 영역(폭 ~H)과 쐐기 액체 때문에 실효 α가 O(H/d) 다르다. 측벽의 기포 없는 층은 병렬 통로라 y를 낮춘다. 부피 포화도(Fourar)는 투영 α와 O(H/d) 다르다.

### 1.5 배치 보정 (점검 5, I74)
- 2차원 Lorentz 국소장으로 풀었다. 기포가 받는 평균 국소장 Ū = F + P/2 + λQŪ. F = K·G, P = J − F = 2αλŪ. 기포 i는 V_i = sU_i로 움직인다고 둔다.
- 결과: w ≡ Ū/U_m = (1 − α)/(1 − α − λQ). 원형 폐합은 w = 1을 가정한 것이다.
  - **측정 B에서 본 잔차**(판별 평면의 잔차): Δy = 2(w − 1) = 2λQ/(1 − α − λQ) ≈ 2λQ/(1 − α), ΔE ≈ 2λQα/(1 − α)².
  - 같은 s에서의 변화: ΔE ≈ λ(1 − λ)Qα/(1 − α)². 이것도 1차다.
  - 유효 투과율 κ = J/(K·G)의 변화만 λ²다: Δκ ≈ 2αλ²Q(Rayleigh 직사각 배열과 같은 꼴). 노트의 λ²는 이 꼴을 E로 옮긴 것으로 보인다. 그러나 E는 측정 B에서 비교하므로 기포 속도(기체 유량)의 1차 변화가 남는다.
  - V = sU_m으로 고정해도(국소장과 무관) 잔차는 같은 1차다.
- x ≈ −λ이므로 Δy ≈ −2Qx/(1 − α)다. 직선은 (0, 1)을 그대로 지나고 기울기만 −2Q/(1 − α) 바뀐다.
- Q(원 합, Lorentz 기준) 공식: 직사각 격자(흐름 방향 ℓ_x, 가로 ℓ_y)는 Q = (πa/ℓ_x)²[1/3 − 2Σ_m sinh⁻²(πmℓ_y/ℓ_x)] − α다. 정사각이면 0이다. 가운데 한 줄(측벽 간격 W = ℓ_y ≫ ℓ)은 (π²/3)(a/ℓ)² − α다. 거울상 없이 원 합을 키우면 고른 배치에서도 +α로 간다(수렴은 약 2W/R로 느림). 쌍극자 장 식과 θ 정의(흐름 방향 기준)는 맞다.

### 1.6 관성 수 (점검 6)
- (6/5)ρU²/d ÷ 12μU/H² = ρUH²/(10μd) = Re_H(H/d)/10. 맞다. 6/5는 포물선 단면의 운동량 플럭스 인자이고 깊이 평균 모형에서 표준이다(근사다).
