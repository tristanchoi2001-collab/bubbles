범위
- `idea_log.md` 묶음 13(I99–I103, 1212–1326행)과 I90의 정정(1045·1050–1054·1074행).
- `tools/velocity_fluctuations.py` 전체(526행), `fig/src/fig_velocity_fluctuations.py`와 그림 r16, `fig/data/i99_dipole_fluct.json`.

행 번호는 2026-10-24 07시(UTC) 무렵의 작업 트리 기준이다. git은 쓰지 않았다.

방법
- 배제 영역이 있는 2차원 쌍극자 합의 특성함수를 직접 적분하고 수치로 뒤집었다(J0는 Abramowitz–Stegun 근사). 같은 모형을 Poisson 몬테카를로로 다시 확인했다.
- 도구의 데모 생성기를 그대로 써서 단계별로 나눠 봤다.
  - 정확한 장·정확한 속도로 순간 회귀와 창 회귀.
  - 도구가 계산한 장과 정확한 장의 비교.
  - 접촉 필터를 주기 경계에 맞게 고친 판, 시드 5개.
  - 현실 시야(1080 × 416 px) 자르기, 시간 상관 잡음, 큰 흰 잡음.
- 평면 Bretherton 뒤 메니스커스를 들어오는 막 두께마다 풀어(RK4, 꼬리 1/ξ 보정) 막 기억의 크기를 냈다. 준정적 값은 β1 3.876, β2 −1.1287로 Booth 2023(3.88, −1.13)과 검토 6(3.8774, −1.1285)에 맞는다.
- I102의 무리 효과는 I89의 가로 운동량 균형과 I91의 Lorentz 국소장으로 유도했다.
- `velocity_fluctuations.py --demo`(70 s, 통과)와 `plane_from_csv.py --selftest-vel`(6 s, 통과)을 돌렸다.
- 웹: WebSearch(standard) 8회, Crossref REST 10건(키·메일 없음, 402 없음). 무료 자료만 썼다.

스크립트는 세션 scratchpad `review7/`에 있고 세션이 끝나면 없어진다: `g_alpha.py`, `mc_check.py`, `mcx2.py`, `push_bug.py`, `demo_probe.py`, `demo_probe2.py`, `demo_probe3.py`, `demo_fixfilter.py`, `seeds.py`, `seeds_fixed.py`, `smooth_noise.py`, `rear_memory2.py`, `rear_table.py`, `jac.py`, `calc_numbers.py`.

## 2. I99: g(α)

### 2.1 묽은 극한의 정확한 꼴
- 확인한 것: ln φ(k) = n∫[e^{ik·u} − 1]d²r = −πn|D||k|다(∫₀^∞(1 − J₀(t))/t² dt = 1). 각 성분은 척도 γ = πn|D| = α|λ|U인 코시다. 노트와 같다.
- 배제 반경 r_ex = 2a(겹침 없음)가 있으면 ln φ = −γ|k|·F(|k|ρ_max), F(x) = ∫₀^x(1 − J₀)/t² dt, ρ_max = |D|/r_ex² = γ/(4α)다.
- F(x) = 1 − 1/x + O(x^{−5/2})다. 그래서 |k|ρ_max ≫ 1인 중심부에서 φ ≈ e^{4α}e^{−γ|k|}다.
  - 뜻: 이웃이 r_ex 안에 있을 확률(1 − e^{−4α})만큼의 꼬리 질량이 빠지고, 남은 분포의 중심부는 코시 × e^{4α}다.
- 반사분위폭: e^{4α}(2/π)arctan(q/γ) = 1/2에서 q = γ·tan[(π/4)e^{−4α}] ≈ γ(1 − 2πα)다.

## 3. I100: 접선·할선과 막 기억

### 3.1 준정적: 맞다
- 원형에서 Booth형 마찰은 국소 법선 속도의 함수라 회전 대칭이다. 그래서 D ∥ V̂이고 크기는 |V|만의 함수다. 2U_vec = V(1 + Δ(|V|))는 벡터식으로 맞다.
- 야코비안: ∂V/∂U = g'(|U|)ÛÛᵀ + (g/|U|)(I − ÛÛᵀ), g'(U) = 2/(1 + Δ + VΔ') = 2/(1 + mΔ).
- 벡터 힘 균형을 수치로 미분했다: Δ 4.8에서 0.47619·0.34483, 비 1.38095다. Δ 1·0.29도 소수 다섯째 자리까지 같다.

### 3.2 막 기억: 뒤 메니스커스는 오래된 막을 걷는다
- 깨끗한 계면에서 앞 메니스커스는 지금 속도로 막을 깐다. 뒤 메니스커스는 같은 가로 위치에서 2√(a² − y²)/V 전에 깔린 막을 걷는다.
- 평면 뒤 문제 η''' = (η − 1)/η³(막이 ξ → +∞)는 한 매개변수 해족이다. 곡률 c는 곧 막 비(들어온 막 / (H/2)(3Ca)^(2/3))다. 준정적이면 c = P0 = 0.64304다.
- 해족을 풀어 꼭짓점 값 c1(c)을 얻었다(ξ = −200까지, 꼬리 −2/(c²ξ) 보정).

  - 중간 주파수에서는 현 길이마다 기억 시간이 다르고, 가로(무게 tanθ)와 흐름 방향(무게 1)의 각도 무게가 달라 R이 몇 % 더 움직일 수 있다(계산하지 않음).

### 3.3 시간 척도
- 탐침이 보는 장은 주로 거리 r_γ ≈ (|D|/γ)^(1/2) 안의 이웃이 만든다. 데모 값으로 작은 탐침 주위의 큰 기포는 r_γ ≈ 114 px, 상대 속도 7.2 px/frame이라 약 16프레임마다 바뀐다.
- 작은 기포의 현 통과 시간은 2a/V = 16/2.07 ≈ 7.7프레임이다. 비는 약 2이다. 같은 크기 이웃끼리는 상대 속도가 거의 0이라 준정적이다.
- 그래서 실제 응답은 두 극한 사이다. 속도 창(2k = 8프레임)도 같은 크기라, 창 k를 바꾸면 기울기가 달라질 수 있다.

### 3.4 압력이 필요하다
- 회귀자의 λ_j = V̄_j/U_loc − 1과 m 역식의 Δ = 2U_loc/V̄ − 1이 모두 U_loc을 쓴다(요약 #6).
- I99의 폭으로 단분산의 |λ|를 얻으면 s = 1 ± |λ|로 U_loc을 낼 수는 있다. 하지만 부호가 모호하고 g의 불확도(§2.2)가 그대로 들어간다.

## 4. I101: 측벽 거울상

- 깊이 평균 퍼텐셜 흐름에서 벽 c = c_w의 불투과 조건 ∂φ/∂c = 0은, 흐름 방향 쌍극자 B·ds/r²을 같은 세기·같은 방향으로 거울에 놓으면 만족된다. 두 항의 벽 법선 도함수가 서로 지워진다.
- 거울상은 기포에서 가로로 2h 떨어져 있다(cos 2θ = −1). 그래서 국소장은 U − λUa²/(4h²)다. 부호는 노트와 Booth 외 2023(무리 쪽 페이지 요약과 Crossref 초록의 "δ − 1의 부호가 행동을 바꾼다")에 맞다.
- 기포는 흐름 방향 국소장 변화에 접선 이동도로 응답한다. 그래서 ΔV/V∞ = −Rλ(a/2h)²다.
  - d/H 3(λ −0.655, R 1.381): +7.3% → +10.0%.
  - d/H 30(λ 0.55, R 1.081): −6.1% → −6.6%.
- 폭 20 mm 채널의 d 9 mm 기포(h/a 1.5)는 반대쪽 벽 거울상이 −1.6%를 더한다(R 배 전). 두 벽을 합해야 한다.
- Brinkman 층: 깊이 평균 식 μ∇²ū − (12μ/H²)ū = ∇p의 감쇠 길이는 H/√12 ≈ 0.29H다. 벽에서 H 떨어지면 결손이 3%다. "h − a < H 제외"는 넉넉하다.
- 같은 거울상 구조가 도구 `dipole_fields`에도 있다. 자기 거울상은 가로 위치만의 함수라, 국소장의 가로 분포(유입부, 국소 α의 가로 기울기)가 있으면 흐름 방향 기울기에 섞인다(요약 #12).

## 5. I102: 가로 기울임

### 5.1 기포 하나: 맞다
- 환산 압력 P = p + ρg sinθ·c(c는 오르막)를 쓰면 액체는 u = −K∇P이고, 기포 기둥에는 부력 ρg sinθ·A·H가 생긴다.
- 원형 쌍극자 해에서 가로 반작용은 −(H/K)A·V_c(C = 1)다. 그래서 V_c(1 + Δ) = Kρg sinθ다. Δ = 0이면 Taylor–Saffman의 ρgH²sinθ/(12μ)가 된다.
- 마찰이 V̂ 방향이고 크기가 |V|만의 함수면, 부력은 가로 국소장 Kρg sinθ/2를 더한 것과 같다. 그래서 V ∥ U_eff이고 tanφ = ρg sinθ·K/(2U_loc)가 Δ와 무관하게 정확하다.
- 수치: 1 mm·0.1 m/s·10 mrad에서 2U/K = 2400 Pa/m, tanφ 0.0408(2.34°), 50 mm에 2.0 mm다. 0.3 mm·0.05 m/s에서 0.00734(0.42°), 0.37 mm(18 px)다. 노트와 같다.
- 틀린 수치: 1 mm·1 mrad면 tanφ 0.00408, 50 mm에 0.20 mm다(노트 20 µm). 0.3 mm·0.05 m/s·1 mrad면 37 µm다.

### 5.2 무리: 측벽이 가로 순유량을 막는다
- 측벽이 있고 통계적으로 흐름 방향으로 고르면 전체 가로 유량이 0이다. 기포가 오르막으로 가면 액체가 내리막으로 돌아온다.
- I89처럼 가로 운동량을 적분한다: −G_c = (1/K)Σ_jα_jV_c,j(Δ_j − 1) − αρg sinθ.
- I91의 국소장(가로 J_c = 0): U_loc,c = U_P,c/2 = −KG_c/2.
- 기포마다 V_c,j(1 + Δ_j) = 2U_loc,c + Kρg sinθ.
- 풀면 V_c,j = Kρg sinθ(1 − α)/[(1 + Δ_j)(1 + Σ_kα_kλ_k)]다. 흐름 방향은 V_s,j = 2U_loc/(1 + Δ_j) 그대로다.
- 그래서 tanφ = [ρg sinθ·K/(2U_loc)]·(1 − α)/(1 + Σα_kλ_k)다.
  - 인자는 모든 크기에 같다. 그래서 "크기와 무관" 예측은 남는다.
  - Σα_kλ_k = j_G/U_loc − α라 측정량으로 계산할 수 있다.

  | α | Σαλ | 인자 |
  |---|---|---|
  | 0.1 | 0 | 0.900 |
  | 0.1 | +0.055 | 0.853 |
  | 0.2 | −0.1 | 0.889 |
  | 0.2 | +0.1 | 0.727 |
  | 0.3 | +0.15 | 0.609 |

- 예: j_L 0.1, B 0.2, α 0.2. 원형 폐합으로 E 0.3, U_P 0.13, J 0.12, U_loc 0.125, Σαλ = −0.04, 인자 0.833이다.
  - 기울임에서 읽은 2U_loc/K는 1.2배다. 연결 2의 K = J/(2U_loc/K − G_P)는 0.71배(−29%), H는 −16%다.
- 이 유도는 평균장(I91과 같은 근사)이다. 직접 수치로 확인하지는 않았다. 기포가 오르막 벽에 쌓여 가로 α가 고르지 않으면 되돌이 흐름도 고르지 않다.

### 5.3 테두리 부피
- 팬케이크 테두리 단면은 지름 H의 반원이다. 영상 윤곽(가장 바깥, 중간 평면) 안쪽의 기체 두께는 바깥에서 H보다 얇다.
- 둘레 길이당 빠지는 부피는 ∫₀^{H/2}[H − 2√(x(H − x))]dx = (1/2 − π/8)H² = 0.107H²다. A·H 대비 0.215H/a = 0.43H/d다.
- 부력은 기체 부피에, Darcy 반작용은 (선도 차수에서) 윤곽 면적에 비례한다. 그래서 tanφ가 d/H 3에서 14%, 5에서 9%, 10에서 4%, 30에서 1.4% 작다.
- 검토 6 #5의 O(0.43H/d) 테두리 보정(부호 미상)도 반작용 쪽에 붙는다. 어느 쪽이든 원형 기포의 tanφ가 크기에 따라 O(H/d)만큼 바뀐다. 이것을 "할선 마찰이 아니다"의 증거로 읽으면 안 된다.

### 5.4 그 밖
- ±θ를 번갈아 평균하면 남은 기울기 같은 더하기 꼴 오차는 지워진다. 무리 인자(5.2)와 벽 근처의 가로 감속(벽 쪽으로 가는 쌍극자의 거울상은 반대 방향이라 접근을 늦춘다)은 곱하기 꼴이라 지워지지 않는다.
- 제목의 tanφ = ρg sinθ/((1 + C)U_loc/K)는 C_xx = C_yy일 때만 Δ가 지워진다. 타원은 C_xx = b/a, C_yy = a/b라 원에서만 같다. 제목은 원형식으로 두는 편이 정확하다.
- Monnet 외 2024(PRF 9:073601)는 기울인 Hele-Shaw에서 갭을 가로지르는 부력이 위·아래 막을 비대칭으로 만든다고 했다. I102는 거의 수평이라 그 성분(g cosθ)이 수평 운전과 같다. 문제없다.

## 6. I103
- 착상과 반증·위험 항목은 그럴듯하다.
- 흡착 시간 척도 (Γ/c)²/D가 머무는 1~2 s와 맞으려면 Γ 2×10⁻⁶ mol/m², D 5×10⁻¹⁰ m²/s에서 c ≈ 0.05~0.1 mM이다. 미량 오염(µM 이하)은 1000 s 이상이라 시야 안에서 시계가 보이지 않는다. 진한 SDS(mM 이상)는 ms 안에 끝난다. SDS 대조는 이 창 안의 농도로 한다.

  - 녹지 않는 미량 오염의 표면압은 보통 몇 mN/m다. 그보다 큰 응력이 필요하면 계면 물질이 뒤로 몰려 정체 모자가 된다. 앞쪽 계면은 움직이고, 마찰은 미끄럼 극한보다 작다.
  - 그래서 "크기와 거의 무관하게 거의 멈춘다"(1045·1074행)는 작은 기포·느린 흐름에서만 맞다. 큰 기포와 빠른 흐름에서는 부분 이동이 되고, 이동도는 크기에 따라 커질 것이다.
  - "s ≳ 0.1로 움직이는 기포는 미끄럼 굳은 막이 아니다"(1054행)는 맞다.

## 10. `plane_from_csv.py` 속도 경로
- `--selftest-vel`: 6점 × (P_2/3, α_멈춤, α_작음, k_fit, E_vel = E, 프레임 평균) + 맞춤 6개, 모두 통과(6.4 s).
- 코드 읽기
  - 잘린 기포: 같은 트랙의 화면 끝에 닿지 않은 프레임 면적의 중앙값을 쓰고, ROI 몫 A_roi/A_참을 곱한다. 창(ROI)에 걸친 기포를 면적 몫으로 세는 것은 평행 이동 평균에서 편향이 없다.
  - 멈춘 기포: s* = 2u/(U_P + J) < 0.1이면 마찰 합에서 빼고 α_멈춤(2 + E + B)를 더한다.
    - 유도: 원형 정지 기포의 Darcy 힘 (H/K)A(2U_loc) = (H/K)A(U_P + J)에서 E 몫이 α_멈춤(U_P + J)/j_L이다. 맞다.
    - 거의 멈춘 기포(0 < s* < 0.1)의 −V 항은 그 몫의 5% 미만이다.
  - 빈 프레임: a_sum = 0이면 배율 1로 0을 더한다. 맞다.
  - 순간식 E_vel_frame = E_D + (j_G − j_G,inst)/j_L의 부호가 맞다.
  - 합체 행(면적 0, ROI 면적 빈칸)은 `A_roi ≤ 0`에서 빠진다.
  - 철 추적기의 속도 열은 영상 좌표 그대로(왼쪽·위면 음수)라 `axis_of`의 부호가 맞다.

## 11. 새로움과 선례 (검색 8회, Crossref 10건)
- I99
  - Shani, Beatus, Bar-Ziv & Tlusty 2014, Nat Phys 10:140–144, 10.1038/nphys2843(Crossref: 제목·저자·쪽 확인, 초록 없음). 검색 요약에 따르면 2차원 미세유로 액적 무리의 속도 상관이 1/r²·4중 대칭이고, 요동(상관) 진폭이 배제 부피 효과로 밀도에 대해 비단조다.
