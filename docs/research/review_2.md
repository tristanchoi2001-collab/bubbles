## 1. 다시 유도한 기준식 (아래 발견의 근거)
- 기호: K = H²/(12μ), G = −dP/dx(탭 사이), j = 전체 겉보기 유속(기체 발자국 포함), U_m = 기포 사이 액체의 평균 속도, s_k = V_k/U_m, α = 투영 기공률.
- **정확한 항등식**(Darcy 영역을 Gauss 정리로 적분, 농도 근사 없음): K·G = j_L,D + (K/(H·A))·ΣF_k. j_L,D는 Darcy 영역의 액체 유속, F_k는 기포 k에 걸리는 액체 압력 힘이다.
- 원형 기포의 힘: F_k = (12μ/H)·A_k·(2U_inc − V_k). U_inc는 기포가 받는 국소 유속이다.
- **Maxwell 방법**(기포 무리를 담은 큰 원의 원거리 쌍극자 = 유효 매질 원의 쌍극자): 유효 매질 구성식은 j = K·G·(1 − α)/(1 + α) + 2·j_fp/(1 + α)다. j_fp = Σα_kV_k(발자국 유속). 이것은 U_inc = U_m과 같은 결과다.
- **정상 상태**(j = j_L(1 + B), j_fp = j_G): E = 2α/(1 − α) − B = α(2 − s̄)/(1 − α) = B(2 − s̄)/s̄. 노트의 식과 같다.
- **순간 꼴**(전체 유속 j가 주어질 때, 과도·요동): K·G/j = (1 + α − Σα_ks_k)/(1 − α + Σα_ks_k) ≈ 1 + 2Σα_k(1 − s_k).
  - 정상값은 1 + E = (1 + B)·[1 + 2α(1 − s̄)/(1 − α + αs̄)]로 나뉜다. +B는 기체가 더한 부피 유속 몫(탭 구간이 물뿐이어도 생김), 괄호는 기포 마찰 몫이다.
- **기체가 멈춘 통로로 흐를 때**(계면 정지, u·n = 0, 기체 유량은 있음): 같은 항등식에서 E = 2α/(1 − α)(원형). −B 항이 없다.
- **쐐기 포함**: φ_L² = (1 + α − 2β_f)/((1 − α)(1 − β)). β_f = 발자국 유속 분율(쐐기 액체 포함). 물리 이동도는 s̄ = β_f(1 − α)/((1 − β_f)α)다.
- **압력 세 값**(쐐기 무시): B = ΔP_on/ΔP_L − 1, E = ΔP_ss/ΔP_L − 1 → s̄_P = 2B/(E + B), 그리고 **α_P = 1 − 2ΔP_L/(ΔP_on + ΔP_ss)**(노트에 없는 꼴. 영상 α와 바로 비교할 수 있다).

## 2. 발견

### 1. [높음] 시간에 따라 변하는 ΔP 식이 틀렸다
- **위치**: `design_predictions.md` 16.1절 282행(지배 식), 284행("내려가 … 걸리는 시간 ≈ L/V_min"), 286행("다시 넣으면 올라간다", "둘의 합이 E·ΔP_L로 일정"). `idea_log.md` I53 382·386·389행. 같은 식이 I46(317행, 순간 폐합 회귀)에도 있다.
- **무엇**: ΔP(t) = ΔP_L·[1 + Σ A_i(2 − s_i)/(W·L·(1 − α))]는 정상 상태에서만 맞는다. 기체를 켜고 끄는 과도나 같은 유량에서의 요동에서는 전체 유속 j(t)가 정해져 있다. 그때 기포 하나의 기여는 (2 − s)가 아니라 2(1 − s)다(1장 순간 꼴).
- **왜**
  - 켤 때: 기포가 탭 구간을 채우는 동안 ΔP는 s̄ > 1이면 **내려간다**. 장난감 모델도 그렇다(1.176 → 1.069, 깨끗한 경우). 16.1의 지배 식은 올라간다고 예측한다.
  - 끌 때: "E·ΔP_L만큼 내려간다"는 전체 폭만 맞다. s̄ > 1이면 곧바로 (1 − β)(1 + E)로 떨어진 뒤 **올라간다**. "크기가 고르면 거의 직선으로 내려간다"도 이 경우에는 틀린다. 장난감 모델의 깨끗한 경우로 보면, 16.1 지배 식은 1.069 → 1.000으로 내려간다고 하지만 맞는 식(장난감 모델의 국소 폐합)은 0.908 → 1.000으로 올라간다. 느린 구간의 방향이 반대다.
  - 거울상: "둘의 합이 E·ΔP_L로 일정"은 틀린다. 묽고 s가 유속에 무관한 선형 모델에서 맞는 관계는 **(1 − β)·ΔP_on(t·(1 − β)) + ΔP_off(t) = ΔP_L·[1 + (1 − β)(1 + E)]**다. 장난감 모델 사본으로 확인했다(차이 ≤ 0.003, 15번).
  - 끝나는 시간: 켤 때 ≈ (X1 + L)/V_min, 끌 때 ≈ (X1 + L)/((1 − β)V_min)다. 장난감 모델에서 2.2 s, 2.5 s다(L/V_min = 1.5 s). 크기 구분 k의 기여도 X1만큼 늦게 시작한다: clip((V_k·t − X1)/L, 0, 1).
  - I46: 요동 회귀의 기울기는 (α 1단위당) **2(1 − s̄)(1 + B)ΔP_L/(1 − α + αs̄)²**다. α 0.15, s̄ 1.5(B 0.265)면 약 −1.1ΔP_L로, I46 식이 주는 +0.59ΔP_L과 부호가 반대다. s̄ ≈ 1이면 요동 신호가 거의 없다. 그러면 I46의 예상("R² 큼", "회귀 계수 = 시간 평균 폐합 값")은 폐합이 맞아도 실패한다.
- **고칠 것**
  - 16.1·I53·I46의 식을 **ΔP(t)/ΔP_L = (j(t)/j_L)·⟨(1 + α − Σα_ks_k)/(1 − α + Σα_ks_k)⟩_탭**으로 바꾼다. 묽으면 (j(t)/j_L)·[1 + 2Σ_i A_i(1 − s_i)/(W·L)], s_i = V_i/U_m(t)다.
  - 16.1의 앞 세 항목(I53 부분)을 뒤의 I58 서술(계단, 넘침/밑돌기, 시간 ÷ (1 − β))에 맞춰 다시 쓴다. 지금은 한 절 안에서 서로 어긋난다.
  - I46의 예상을 "기울기 ∝ (1 − s̄), s̄ > 1이면 음수"로 고친다. 회귀 기울기와 평균 E는 서로 다른 양이다.

### 2. [높음] "넘침·밑돌기로 오염을 진단한다"는 성립하지 않는다
- **위치**: `research_microgap_paper.md` 34행("ΔP만으로 오염 진단"), `idea_log.md` 445행(I58), `design_predictions.md` 288·290·320·334행, 그림 r6 범례("clean" / "contaminated").
- **무엇**: 넘침·밑돌기의 부호는 s̄ − 1의 부호다(이 유도는 맞다). 그런데 s̄는 계면 상태보다 기포 크기와 Ca가 더 크게 정한다.
- **왜**(Booth 식)
  - 깨끗한 계면은 δ = 1.12·Ca^(1/3)·d/H이고, s = 1은 δ = 1이다. Ca = 10⁻³(U ≈ 0.07 m/s)이면 d/H ≈ 9다. 깨끗해도 d/H < 9면 s < 1이라 넘침이 없다. r7 스크립트로 깨끗한 d/H 3은 s = 0.24~0.79다.
  - 굳은 계면(계수 0.444)도 d/H > 22면 s > 1이다. 추정 5.4절 판별력 표의 굳은 계면 d/H 30 행(V/j 1.06~1.48)을 s = V/U_m으로 바꾸면 약 1.1~1.6이다.
  - 그래서 "넘침 없음"은 "작은 깨끗한 기포"와 "오염"을 가르지 못한다. 설계 17장의 "계면활성제를 넣으면 단조"도 큰 팬케이크에서는 틀릴 수 있다.
- **고칠 것**
  - "ΔP만으로 오염 진단" → "ΔP만으로 s̄가 1보다 큰지 작은지를 안다. 오염은 크기 분포와 Ca를 넣어 Booth 식의 c를 거꾸로 구해 판정한다."
  - r6 범례를 "fast bubbles (s̄ > 1)" / "slow bubbles (s̄ < 1)"로 바꾼다.
  - 계면활성제 실험의 예상은 "같은 크기 분포에서 s̄가 내려가 넘침이 줄거나 사라진다"로 쓴다.

### 3. [높음] "멈춘 기포·채널링에서도 식이 성립한다"는 과장이다
- **위치**: `research_microgap_paper.md` 33행("Kumagai 2008이 본 1 mm 채널링에서도 시험이 깨지지 않는다"), `design_predictions.md` 229행("채널링이 생겨도 α·β 시험은 그대로"), `idea_log.md` 418행(I56), `PROGRESS.md` 101행.
- **무엇**: −B 항은 기체가 기포 발자국과 함께 움직일 때(j_G = Σα_kV_k)만 생긴다. 기체 보존이 속도 분포를 지우는 것도 이 조건에서다.
- **왜**
  - (가) 기체가 멈춘 기체 통로를 따라 흐르면(기체 채널링) 계면은 서 있고 기체 유량은 0이 아니다. 1장 항등식으로 E = 2α/(1 − α)(원형)다. α·β 식은 B만큼 작게 예측한다. 예: α/(1 − α) = B인 점이면 α·β 식은 E = B, 채널링이면 E = 2B로 두 배다.
  - (나) 멈춘 기포가 지나가는 기포를 흡수해 자라는 동안은 국소 기체 유량이 유량계 값보다 작다. α도 시간에 따라 커진다. 정상 상태가 아니다.
  - (다) 접촉선으로 붙은 기포는 둥글지 않다. 멈춘 기포의 기여 c·α/(1 − α)는 모양 인자 c = 1 + b/a에 그대로 비례한다. 흐름 방향으로 2배 길면 25% 작다.
  - Kumagai 2008의 "채널링"은 "액체가 멈춘 기포 사이로 지나간다"로만 요약돼 있다. 기체가 계속 주입되는데 기포가 멈춰 있다면 기체는 (가)나 (나)의 길로 빠져야 한다.
- **고칠 것**
  - "고립된 멈춘 기포가 기체를 나르지 않고, 그 수가 늘지 않으며, 원에 가까우면 식이 유지된다"로 좁힌다.
  - "기체가 멈춘 통로로 흐르면 E = 2α/(1 − α)로 바뀐다. 두 예측의 차(= B)로 채널링을 판별할 수 있다"를 덧붙인다(새 진단으로 쓸 수 있음).
  - Kumagai 2008의 채널링이 기체 통로인지 고립 기포인지 원문 그림으로 확인한다.

### 4. [중간] 계단 측정(I58)의 실험 함정 몇 가지가 빠졌다
- **위치**: `idea_log.md` I58(440~455행), `design_predictions.md` 16.1절(288~296행), 17장 6.
- **무엇과 왜**
  - (가) **액체 쪽 컴플라이언스**. 주입부 위쪽에 공기 방울, 연한 관, 맥동 완충기가 있으면, 기체를 켤 때 오른 주입부 압력이 그 부피에 액체를 잠시 저장한다. 하류 유속은 곧바로 j_L + j_G가 되지 않고 τ = C·R로 오른다. 0.3 mm(폭 20 mm, 주입부 하류 0.2 m)면 R = 12μL/(H³W) ≈ 4.4×10⁹ Pa·s/m³다. 대기압 공기 10 mL면 C ≈ 10⁻¹⁰ m³/Pa → τ ≈ 0.4 s로 측정 창(0.5 s)과 같다. 정량 펌프여도 생긴다. I58 조건 (1)은 "압력 둔감"만 다룬다.
  - (나) **끌 때 밸브 배치**. 3방향 밸브가 주입부 쪽을 대기로 열면 채널 압력(0.3 mm에서 약 1~2 kPa 게이지)이 액체를 주입관으로 밀어 넣는다. 하류 유속이 j_L보다 작아져 s̄ < 1이어도 가짜 밑돌기가 생길 수 있다. 다음에 켤 때는 관 속 액체를 먼저 밀어내야 해서 계단이 늦어진다.
  - (다) **기체 공급의 시작 과도**. 다공질 마개(I54)는 기포점 압력(2σ/r_pore, 반지름 10~50 µm면 약 3~14 kPa)이 있다. 쌓인 기체가 한꺼번에 나오면 j_G가 처음에 설정값을 넘는다. 그러면 탭 구간이 물뿐인 동안에도 ΔP가 뛰었다가 내려가 "넘침"처럼 보인다. 처음 나오는 기포가 정상 상태보다 클 수도 있다. 그러면 앞쪽 기포의 s가 정상 s̄보다 커서 넘침의 모양이 정상 상태를 대표하지 않는다.
  - (라) **평평한 구간의 길이**. X1 ≳ V_max·(5H²/(π²ν) + 관로·공급 시정수)가 필요하다. 1 mm·j 0.2 m/s(V_max ≈ 0.36 m/s)면 X1 = 50 mm는 0.14 s뿐이다. 점성 정착(약 0.5 s)도 못 기다린다. 이 방법은 작은 갭·저유속용이다.
  - (마) **단상 비선형**. 1 mm 고유속은 입구 영역 때문에 ΔP_1φ(j)가 직선이 아닐 수 있다.
  - (바) **끝 기준선**. 끈 뒤 홈(I51)이나 막 파열(I56)로 붙은 기포가 탭 구간에 남으면 끝 값이 ΔP_L·(1 + 2α_붙음/(1 − α_붙음))이 된다. "기준선 표류 없음"이 깨진다.
- **고칠 것**
  - 주입부 위쪽 관을 단단하게 하고 공기를 빼서 C·R ≪ 0.1 s로 만든다. 물만 흘리며 유량 계단을 줘서 정착 시간을 먼저 잰다(I58의 덮개 처짐 점검과 같은 시험).
  - 끌 때는 주입부 쪽을 **막고**(L형 밸브) 기체원만 대기로 돌린다. 주입관 압력을 함께 기록한다.
  - 첫 기포가 첫 탭에 닿는 시각을 영상으로 찍는다. 그 전 평평한 구간만 β에, 그 뒤만 넘침에 쓴다. β 계단은 바늘 주입기로 잰다.
  - 계단 값은 1/(1 − β)로 바로 바꾸지 말고 단상 보정 곡선 ΔP_1φ(j)를 거꾸로 읽어 j를 구한다.
  - 끝 프레임에서 탭 구간이 비었는지 영상으로 확인한다.
  - 대조: 끄는 순간의 비 ΔP(0+)/ΔP_ss = 1 − β도 β를 준다(s가 유속에 둔감하면, 15번). 켤 때 값과 비교하면 공급 과도를 걸러낸다.

### 7. [중간] 새 s̄ 꼴들이 쐐기 보정을 빼서 세 s̄가 서로 어긋난다
- **위치**: `estimates_microgap.md` 209행, `research_microgap_paper.md` 22행, `idea_log.md` I61(487~500행), `design_predictions.md` 294행.
- **무엇**: s̄_I = B(1 − α)/α는 기체 부피 = 투영 면적 × H로 놓은 값이다. 5.4절 "쓰는 법"은 발자국 유속 β_f(> β)를 따로 쓴다. 새 꼴들은 이것을 다시 뺐다.
- **왜**: 물리 이동도는 s̄ = β_f(1 − α)/((1 − β_f)α), β_f ≈ β/(1 − 0.43H/d)다. 같은 보정이 s̄_P에는 다른 꼴로 들어간다: s̄_P = β(1 − α)/(α − β_f + β(1 − α)).
  - 예: d/H 3, β 0.2, 실제 s̄ 0.6이면 s̄_I = 0.49(−18%), s̄_P = 0.56(−6%), s̄_T(I61 정의) = 0.58(−4%)다. 모든 측정이 맞아도 대각선에서 최대 18% 벗어난다.

  - I61이 적은 우연 오차(6%, 11%)와 같거나 크다.
- **고칠 것**
  - 세 s̄를 같은 발자국 기준으로 쓴다: s̄ = β_f(1 − α)/((1 − β_f)α). β_f는 추적이 있으면 영상(Σα_iV_i/j)으로, 없으면 크기 분포와 α_vol/α_p 모형으로 β에서 바꾼다.
  - s̄_P는 φ_L² = (1 + α − 2β_f)/((1 − α)(1 − β))로 다시 정의한다. 이때 β_f는 압력만으로는 안 나오므로 "압력만으로 s̄"에는 크기 분포가 필요하다(d/H ≳ 30이면 무시 가능)고 적는다.
  - 16.2 주입기 바꾸기도 작은 기포 쪽 쐐기 보정(d/H 3에서 β_f/β = 1.17)을 넣은 뒤 비교한다. 넣지 않으면 폐합이 맞아도 두 주입기의 선이 갈릴 수 있다.

### 9. [중간] C와 미끄럼의 연결에는 고전 선례가 있고, "장치마다 다른 C를 설명한다"는 과장이다

### 10. [중간] I57 "폐합 = 증발 센서"의 교란 요인과 판별력

  - 액체와 기체를 시험 온도로 미리 데우고 열유속을 작게 한 **거의 등온 운전**을 따로 둔다. (가)가 사라지고 증발(가습)만 남는다.
  - 비교 변수를 B_eff/B_in으로 바꾼다.

### 11. [중간] 초록 초안에서 고칠 문장
- **위치**: `abstract_drafts.md` 11행(영문), 14행(한국어), 19·23행, 32·35행(논문 2).
- **무엇과 고칠 것**
  1. "We show that … follows from two kinematic quantities alone" → 원형·α ≲ 0.3·Darcy·평균장 조건과 쐐기·모양 보정을 적는다. 실험 전 초안이므로 "We test whether …"가 맞다.
  2. "φ_L² − 1 = B(2 − s̄)/s̄, where s̄ = B(1 − α)/α" → 대입하면 2α/(1 − α) − B다. s̄가 따로 잰 값처럼 읽힌다. 기본식은 2α/(1 − α) − B로 두고 "equivalently, B(2 − s̄)/s̄"로 쓴다.
  3. "Three independent estimates of s̄" → 독립이 아니다. s̄_P는 폐합을 가정해야 나오고, s̄_I와 s̄_T는 같은 α를 쓴다. "Pressure and image estimates agree (a test of the closure); image and tracking estimates agree (a test of gas conservation)"로.
  4. "The fitted Chisholm parameter therefore reflects bubble mobility" → 주입기 실험의 결론이 아니라 폐합의 대수적 귀결이다. "In Lockhart–Martinelli form the closure implies …"로 쓰고 Chisholm 1967을 인용한다(9번).
  5. "At 3 and 7 mm the closure fails in the way predicted by buoyancy (half-gap Bond number)" → 3 mm는 Bo_b = 0.30 < 1이라 부력이 큰 기포를 떼지 않는다. 3 mm에서 깨지는 원인은 갭보다 작은 기포와 관성(Re_H·H/d 최대 약 1000)이다. 노트에는 "어떻게 깨지는지"의 정량 예측이 없다. "We map where and how it fails"로.
  6. 논문 2 "Heat transfer drops below the single-phase value at 0.3 mm and low passage frequency" → 70~90 °C에서는 0.3 mm 발자국의 열관 전도(약 3~14 kW/m²K, 12번)가 액체 h(약 5.9 kW/m²K)와 같거나 크다. "≲ 50 °C" 같은 온도 조건을 붙인다.
  7. 논문 2 "following the slope of the saturation vapour pressure" → 확산 열관은 (dp_sat/dT)·P/(P − p_v)를 따른다. Stefan 인자 P/(P − p_v)가 90 °C에서 3.2배라 기울기만으로는 모양이 다르다.
  8. "coefficients rarely transfer between facilities" → 근거 문헌을 붙인다. Kim & Mudawar 2012 같은 범용 상관식은 여러 자료에 평균 오차 약 20%대로 맞는다고 주장한다. 반론을 미리 적어 둔다.

## 3. 확인해서 맞은 것
- **1(a)**: E = B(2 − s̄)/s̄, s̄ = B(1 − α)/α는 대수적으로 맞다(쐐기 무시 기준). s̄ = 1 → B, 2 → 0, 0.5 → 3B도 맞다. s̄ = 1에서 E = B는 "기포가 쌍극자를 만들지 않아 혼합물이 유속 j의 액체처럼 흐른다"는 뜻이라 물리적으로도 맞다.
- **1(b)**: 두 상 층류·같은 채널에서 1/X² = (μ_G/μ_L)·B, C = X·E − 1/X → 노트의 C 식과 같다. √(μ_L/μ_G) = 7.44(μ_G 1.81×10⁻⁵ Pa·s).
- **1(c)**: Lee & Lee를 다시 계산했다. 1 mm·20 mm·j_L 0.1: D_h 1.905 mm, λ 7.25×10⁻⁶, ψ 1.38×10⁻³, Re_Lo 190, C 0.065. β 0.2에서 1/X² 0.0045, C/X 0.0044, E 0.0089. 0.3 mm·j_L 0.05: C 0.0030, E 0.0047. C ∝ j^1.28. 모두 노트와 같다.
- **폐합 자체**: E = 2α/(1 − α) − β/(1 − β)를 Maxwell 방법으로 다시 얻었다. 국소장 = U_m과 같은 결과다(1장).
- **2(a)**: 계단 1/(1 − β)는 정유량·층류·탭 구간 물뿐이면 모델 없이 맞다.
- **2(b)**: ΔP_ss − ΔP_on = ΔP_L(E − B) = ΔP_L·2α(1 − s̄)/(1 − α). 맞다.
- **2(c)**: 끌 때 즉시 (1 − β)(1 + E), 밑돌기 ⟺ s̄ > 1, 밑돌기 깊이 (1 − β)·2α(s̄ − 1)/(1 − α). s 고정 가정에서 맞다. 시간 ÷ (1 − β), 크기 × (1 − β)도 선형 모델에서 맞다(거울상의 상수만 1번처럼 고침).
- **2(d) 장난감 모델**
  - 국소 폐합 K·G = U(1 + α) − Σα_kV_k는 Maxwell 구성식과 같다. U_loc = j/(1 − α + Σα_ks_k)는 비압축(단면 전체 유속 균일)을 정확히 만족한다. 정상 끝 값 1.069/1.314 = 1 + E로 돌아온다.
  - 풍상 차분은 보존형 공여 셀이다. 속도가 양수이고 CFL 0.4, 특성 속도 f′ = V/(1 + α(s − 1)) ≤ 1.09V라 안정하다. 1차라 앞선이 조금 번지지만 모양 그림에는 충분하다. 유입 경계(α_kV_k = g_k·j_G)도 맞다.
  - 기체 압축(0.3 mm 채널 안 부피 변화 약 0.2~2%), 점성 정착(H²/(π²ν) 0.01~0.1 s), 막 재배치(d/V 약 0.05~0.3 s)는 모양을 바꾸지 않는 작은 효과다. 모양을 바꿀 수 있는 것은 4번의 공급 쪽 효과, 2번의 크기 의존, 합체·크기 분류(앞쪽에 빠른 큰 기포)다. 크기가 섞여 s가 1 양쪽에 걸치면 곡선이 단조가 아닐 수 있다(부호는 여전히 s̄ − 1).
- **I61**: s̄_P = 2(ΔP_on − ΔP_L)/(ΔP_ss + ΔP_on − 2ΔP_L) 맞다. B 0.25·s̄ 1.5에서 ±0.09(6%), s̄_I ±11.7%도 맞다.
- **I58**: ΔP_L 668 Pa, β 0.05의 계단 35 Pa, 0.5 Pa 분해능으로 β ±1.35%, 점성 정착 시간, 관성 압력 자릿수 모두 맞다.
- **I57**: B = 2α/(1 − α) − E, β_eff = B/(1 + B) 맞다. 부피 배수 1.26/1.69/4.0과 1.10/1.17/1.24, 설계 18장의 잠열 4/13/64 W(공기 1 L/min당)도 맞다(건조 공기, 완전 포화 가정).
- **I59**: k_g/H ≈ 90 W/m²K(0.3 mm), 1 mm 열관 0.3~4 kW/m²K 맞다.
- **I60**: ΔT = qH/k를 쓴 산술(Ma ≈ 1600, 힘 비 ≈ 1)은 맞다(13번은 ΔT 자체의 인자).
- **r7**: δ = 1.12·Ca^(1/3)·d/H는 힘 균형에서 3π/(1.68 × 5.01) = 1.12로 나온다. Ca를 U_m으로 잡은 것은 s = V/U_m, 평균장 국소장과 일관된다. 출력한 C 값을 재현했다. "같은 d/H·Ca면 갭 무관", "유속과 함께 감소(B 고정)"는 Darcy 모델 안에서 맞다.
- **보고서 ①·④와 1~4의 일관성**: 식과 계단 값(1/(1 − β), s̄_P)은 서로 맞는다. 어긋나는 곳은 위 1·2·3·5·7·9번이다.
