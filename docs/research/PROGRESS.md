## 비용 규칙 (최우선, 사용자 지시 2026-10-23)
- 추가 비용이 생기는 외부 서비스·유료 API·유료 검색·유료 도구는 쓰지 않는다. 무료 공개 API와 공개 웹페이지만 쓴다.
- API 키를 발급하거나 쓰지 않는다(OpenAlex 키 포함). 환경변수에 키가 있어도 쓰지 않는다.

- 비용이 생길 수 있는 작업은 하기 전에 멈추고 사용자 승인을 받는다.
