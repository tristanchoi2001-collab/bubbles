# 현황 요약 (2026-10-23)

## 결론
- **투명(백라이트) 채널은 현 단계에서 개선·개발을 멈춘다.**
  - 작은·중간 기포의 검출과 추적은 쓸 만한 수준이다.
  - 거대 슬러그는 입력 영상에 안/밖을 가를 단서가 없어서 풀지 못했다.
- **철(불투명) 채널에 집중한다.**
  - 기포 내부가 액체보다 25~45 계조 어둡다. 잡음의 약 13배라 5채널 U-Net으로 검출할 수 있을 것으로 본다.
  - 코드(`steel/`)는 준비됐다. 다음은 라벨링과 PC 학습이다.
- **연구는 1/3/7 mm 마이크로갭 비교 논문으로 간다.** 열전대·압력계·영상 데이터를 함께 쓴다. 방향은 `docs/research_microgap_paper.md`에 정리한다.

## 1. 공통 파이프라인
원본 + 배경 → 배경차분·이진화 → U-Net(배경 / 기포 내부 / 기포 경계 3클래스) → 경계를 벽으로 삼은 영역 분할(hybrid) → 기포 인스턴스 → 헝가리안법 추적(합체·분열 판정 포함) → `result_tracking.csv`, `result_area_count.csv`, `qc_report.json` → `3_tracking_qc.py`(자동 점검), `4_link_audit.py`(사람이 표본을 판정해 실제 연결 정확도 추정).

### 안 된 것과 근거
- **거대 슬러그의 안/밖** — 입력에 정보가 없다.
  - 화면 안의 닫힌 기포: 내부가 주변 액체보다 −5 계조(중앙값, 17개 중 17개).
  - 화면 끝에 닿은 거대 슬러그: 경계 근처 −1~−2, 안쪽은 +2~+3. 잡음(σ ≈ 3) 수준이다.
  - 1200×480 조건 원본(15.jpg)은 화소의 92%가 255로 포화돼 있다.
- **모델로 메우려던 시도는 모두 효과가 없었다.**
  - TAU(사전 마스크 입력): 두 번 학습했고, 두 번 다 사전 마스크 가중치가 0에 가깝게 남았다(쓰지 않음).
  - 부호 채널 DK/DB: 절제해 보니 화상 내용의 기여가 거의 없었다. 기여분의 85~90%가 상수항이다.
  - 트랜스포머(맥락 모듈): 절제해 보니 효과가 없었다(확률 변화 0.25%, 잡음 수준).
- **위상 규칙(parity)** — 사용자 750프레임 시험.
  - 된 것: L자 슬러그(632~645)를 복구했다.
  - 문제: 추가 489개 중 3프레임 이상 이어진 것은 172개뿐이고, 1프레임짜리가 241개다.
  - 화면 안쪽 추가 109개 중 연속된 것은 9개뿐이다.
  - 확인 그림이 이진화 화상 위에 그려져 있어 사람이 판정하기도 어렵다.

### 재개할 때의 출발점

## 3. 철 채널
### 측정 (학습 없이 원본으로 잼)
| 항목 | 값 |
|---|---|
| 기포 내부 − 액체 | 단일 기포(44/45) 약 −40(잡음의 약 13배, 내부/액체 AUC 1.00). 직경 100~230 px 기포는 중심까지 −25~−45 |
| 큰 슬러그 | 테두리에서 50~100 px까지 −20~−30, 중심은 −5~−10(거대 슬러그 중심은 ≈0) |
| 테두리 | 폭 20~25 px의 밝은 띠(+30~+85) + 그 안쪽의 어두운 띠 → DB/DK 채널이 나뉜다 |
| 흐름 | 오른쪽으로 48~53 px/프레임 |
| 배경과의 어긋남 | 프레임 0·492는 x −0.75~−1.0 px. 18·21은 dx 0.5~1.7, dy 2.1~2.8 px, 세로 배율 0.9964~0.9968 |
| 위치 맞춤 효과 | 국소 잔차 8.0→4.8(18·21), 조용한 영역의 이진화 오점등 7.2%→1.05% |
| 거품 | 직경 5~8 px 미세 기포 무리. 간격 약 10 px에 프레임당 약 50 px 이동이라 하나씩은 추적할 수 없다 |

### 준비된 코드 (`steel/`, 테스트 9개)
- 배경 위치 맞춤 `BG_REGISTER='affine'`(프레임마다, 실패하면 직전 값).
- 흐름 방향 `FLOW_DIRECTION="right"`(선단·후단과 속도 열).
- 밝기 맞춤은 끔(`BG_MATCH=None`. 슬러그가 화면 대부분이면 틀림).
- 원래 BMP 읽기(`ORIGINAL_IMAGE_DIRS`).
- 철 화면용 기본값(CROP 672², 좌우 반전 증강, MAX_SPEED 100 등).

### 다음 단계
1. 라벨링(Roboflow). Gemini 자동 라벨 + 수정으로 시간을 줄인다. 기포마다 폴리곤 1개를 밝은 테두리 바깥 가장자리에 그리고, 거품은 하나씩 그리지 않는다.
2. PC 학습. **같은 라벨로 5채널('bin+sign')과 3채널('bin')을 둘 다 학습해 비교한다.** 5채널이 낫다는 주장의 근거가 된다.
3. 검출 확인 → 추적 QC → 연결 감사(크기별 100건).
4. 위험 요소
   - 거대 슬러그 중심부의 대비가 −5~−10으로 약하다.
   - 거품 무리는 면적으로만 집계할지 정해야 한다.
   - 조명이 고르지 않다(배경 90~180).

## 5. 이번 프로젝트의 교훈
1. 재학습 전에, 기존 모델로 "망가뜨린 val"을 평가해 문제가 실제로 있는지부터 본다(TAU에서 놓침).
2. 새 입력 채널을 설계하기 전에, 그 단서가 원본에 있는지 1장으로 잰다(부호 채널, 투명 채널 내부).
3. 가중치 크기만으로 "쓴다/안 쓴다"를 판단하지 않는다. 절제(0으로 만들어 추론)로 확인한다.
4. 규칙 기반 구제는 한 프레임만 보고 판정하면 불안정하다. 시간 일관성으로 확인해야 한다(parity).
